01 / CONTEXT

项目背景 & 行业机会

睡眠与情绪健康赛道持续增长，非侵入式脑机接口（EEG）成本下探至消费级区间，但行业长期存在「采集难标准化、反馈无闭环、数据无沉淀」三大断点：硬件厂商卖完即止，算法团队缺少落地场景，用户拿不到可感知的价值。

Lumi 的机会点在于：以一套标准化脑波 SDK 同时服务两类客户——ToC 端用「脑波头戴 + 声光反馈 + APP」套装建立消费样板，ToB 端把同一套 SDK 作为算法服务交付给硬件与场景方，两端共享同一数据与能力底座。

03 / SEGMENTS

用户分层

ToC 用户

睡眠障碍 / 高压疗愈人群

痛点

  • 入睡困难、焦虑压力大，缺少非药物干预手段
  • 市面助眠产品「无感知反馈」，不知道有没有用
  • 穿戴设备数据冰冷，无法转化为可执行的改善建议

核心需求

  • 实时、可视化的脑波状态反馈
  • 声光 + 香薰的多感官沉浸式放松体验
  • 长期趋势报告与个性化课程

ToB 客户

硬件厂商 / 疗愈空间 / 健康场景方

痛点

  • 自研脑波算法门槛高、周期长、效果难验证
  • 缺少标准化的采集与解析能力，项目制成本高
  • 硬件同质化严重，需要差异化卖点

核心需求

  • 开箱即用的标准化 SDK 与交付文档
  • 稳定的蓝牙协议与跨平台支持
  • 可商务结算的授权模式与落地案例背书

05 / TRADE-OFFS

需求策略 & 取舍

问题约束我的决策取舍代价
脑波指数算法自研还是外采团队算法人力有限，上市窗口紧核心频段解析自研，睡眠分期外采合作外采部分毛利让渡，需锁定排他与数据归属条款
香薰联动是否进 V1.0硬件联调资源只够一条反馈链路V1.0 只做脑波灯闭环，香薰顺延至 V1.1发布会传播点减少，靠灯效 Demo 撑场
SDK 开放到什么程度开放越多越易被抄，越少越难卖开放指数与事件回调，原始数据分级开放部分大客户流失，保住了核心数据资产
APP 自研还是小程序iOS 上架周期与 BLE 后台限制原生 APP 优先，小程序做轻量引流研发成本上升，换来稳定连接与推送能力

06 / SOLUTIONS

双端方案

在手机上体验配套 APP 交互原型→

套装能力

脑波头戴 + 脑波灯 + 香薰灯 + APP 四位一体：实时脑波可视化、声光联动放松课程、睡眠报告与趋势追踪。

盈利方式

套装硬件毛利 + APP 订阅课程 + 香薰耗材复购，三层收入结构摊薄硬件获客成本。

09 / RETRO

复盘风险 & 后续迭代路线

复盘 · 已知风险

  • 消费级 EEG 信号质量受佩戴影响大，需持续投入佩戴检测与滤波策略
  • 香薰耗材供应链波动，影响套装交付节奏
  • ToB 客户定制化需求侵蚀标准化边界，需守住 SDK 红线

后续迭代路线

  • V1.4：睡眠分期算法升级，接入更多反馈设备（音箱/窗帘）
  • V2.0：开放平台计划，第三方开发者接入脑波指数
  • ToB：行业解决方案包（疗愈空间 / 企业减压 / 养老机构）
